# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-09-25

### Added

- Standalone TauriTavern-compatible extension manifest and runtime entry point.
- Current-chat export to TXT, single-file HTML, or both formats.
- All-swipe normalization with current-swipe markers and hidden system-floor filtering.
- Independent `extra.reasoning` omission without rewriting message-body reasoning tags.
- In-memory preview dialog for TXT and sandboxed rendered HTML.
- Sanitized HTML output with image inlining attempts and explicit external-image markers.
- Fixture-based unit tests, repository structure checks, and GitHub Actions CI.
- Synthetic preview files with no real chat data.
